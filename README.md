# 像素小屋简历

李梦媛的互动式像素风简历网页。纯 HTML/CSS/原生 JS，无构建工具、无后端、无任何 API Key。

## 怎么打开

**方式一（最简单）**：直接双击 `index.html`，浏览器打开就能用。

**方式二（体验更完整）**：在本项目目录下起一个本地静态服务器，可以解锁颜色量化（照片像素化效果会更丰富）：

```bash
npx serve
```

或者

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

两种方式的区别：直接双击（`file://`）时，浏览器出于安全限制会跳过"颜色量化"这一步（控制台会有一条提示，不影响正常使用），基础的像素化效果（马赛克感）完全正常；用本地服务器打开则两个效果都生效。

**关于缓存**：`index.html` 里所有 CSS/JS 引用都带了 `?v=9` 这样的版本号，每次我改完文件都会把这个数字往上加一——这样你刷新页面时浏览器一定会去拿最新文件，不会出现"改了一部分文件、浏览器还留着另一部分老版本"的缝合状态。如果哪天发现改动没生效，先看看是不是这个版本号忘了加。

## 怎么加照片 / 视频

**照片（比如 coser 接委托）**：
1. 把照片文件放进 `assets/photos/raw/` 文件夹。
2. 打开 `js/content.js`，找到对应板块（目前是 `cosplay` 的第二个 tab「接委托日常」），把文件名加进 `files` 数组，例如：

   ```js
   { type: 'gallery', dir: 'assets/photos/raw', files: ['cos-01.jpg', 'cos-02.jpg'], caption: '...' }
   ```

3. 刷新页面，照片会自动被像素化滤镜处理后展示，不需要额外处理原图。

**视频（舞蹈社团）**：把视频文件放进 `assets/videos/`，在对应 `videos` 板块的 `items` 数组里加一项 `{ src: 'assets/videos/xxx.mp4', caption: '...' }` 即可。视频没有做逐帧像素化（性能/兼容性考虑），用的是原生播放器 + 复古滤镜（对比度/饱和度 + 扫描线），风格上跟像素房间保持一致。

**"卖小卡"板块目前是装饰性 SVG 插画，不是真实照片**——找不到本人真实照片时，我不会用网上搜到的陌生人照片顶替（那样既有版权问题，也会让作品集里出现不真实的个人经历证据）。以后找到自己的真实照片，把 `photocards` 板块里的 `illustration` 块换成 `gallery` 块（写法同上）就行。

## 怎么改文字内容

所有简历文字都在 `js/content.js` 里，一个 `window.RESUME_DATA` 对象，改文字直接改这个文件里的字符串就行，不涉及 HTML/CSS。

## 项目结构

```
pixel-resume/
├─ index.html          页面骨架
├─ css/                样式（base 基础变量 / room 房间场景 / panel 弹窗 / resume-mode 简历模式+打印）
├─ js/
│  ├─ content.js        全部简历数据（唯一数据源）
│  ├─ pixelate.js       Canvas 像素化滤镜工具
│  ├─ render.js         数据块 -> DOM
│  ├─ panel.js           弹窗开关/tab/焦点管理/#hash 深链
│  ├─ room.js            房间热点 + 移动端底部图标栏
│  ├─ contact.js         联系方式点击显示+复制
│  └─ main.js             入口
└─ assets/
   ├─ room/              房间背景/道具美术图（目前是 CSS 占位样式，还没有真实美术）
   ├─ photos/raw/          coser 接委托等原始照片放这里
   └─ videos/               舞蹈排练视频放这里
```

## 当前状态 & 后续可以做的事

- **房间美术是占位版**：现在用 CSS 画的色块 + emoji + 文字标签表示每个道具，所有交互（点击/hover/键盘/面板/tab）已经完整可用。真实像素画（房间背景图 + 道具贴图）画好后放进 `assets/room/`，把 `css/room.css` 里 `.hotspot` 的占位样式换成透明热区叠加背景图即可，不需要改任何 JS 逻辑。
- **像素字体**：目前标题用等宽字体模拟像素感，正文用系统字体保证可读性（像素风作品集最容易踩的坑就是正文也用像素字体导致看不清）。如果想要更地道的像素字体效果，可以找一个免费的中文像素字体（如 Zpix）放进 `assets/fonts/`，在 `css/base.css` 里加 `@font-face` 并替换 `--font-pixel` 变量。
- **9 个热点已实现**：显示器（职业经历）、书架（教育背景）、笔记本+台灯（AI 项目）、衣柜（小红书账号+coser 接委托）、收纳盒（卖小卡）、海报（舞蹈社团）、奖状墙（其他信息）、信箱（联系方式）、玩偶彩蛋（关于我）。
- **发布**：目前设计为本地自用。如果以后想发布到 GitHub Pages / Vercel 等平台，是纯静态文件，直接拖上去就行；但发布前建议重新考虑一下联系方式的展示方式和照片是否要公开处理（当前版本是按"仅自己本地用"的假设做的，没有做发布级别的隐私处理）。
